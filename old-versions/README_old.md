# Пътен Пазител (RoadGuardian)

## За проекта
Пътен Пазител е платформа за докладване и проследяване на инциденти с диви животни по пътищата в България. Проектът включва уеб баз данни с Leaflet карта, мобилно приложение (Flutter) и Node.js/MySQL бекенд.

---

## 🌐 Уеб интерфейс (Българска версия)

### Структура
- `public/` – лендинг страница и публична карта на инциденти.
- `backend/` – Node.js/Express сървър с MySQL база данни.
- `lib/` – Flutter мобилно приложение (в разработка).

### Бърз старт
1. **Бекенд**
   ```bash
   cd backend
   npm install
   cp .env.example .env
   # Редактирайте .env с вашите MySQL данни
   npm run init-db  # Създава база и таблици
   npm start        # Стартира на http://localhost:3001
   ```

2. **Уеб интерфейс**
   ```bash
   cd public
   python -m http.server 5173
   # Отворете http://localhost:5173
   ```

### Функционалности
- **Публична карта**: Всеки може да разглежда инциденти без вход.
- **Докладване**: Влезлите потребители могат да докладват инциденти (дълго натискане върху картата).
- **Админ инструменти**: Администратори могат да маркират инциденти като „Обработано“.
- **Български контакти**: Спешна помощ (112), БАБХ, РИОСВ.
- **Гео-ограничение**: Картата е фокусирана само върху България.
- **Защита при шофиране**: Показва предупреждение при скорост > 25 км/ч.
- **JWT автентикация**: Сигурен вход с токени.

## 📱 Мобилно приложение (Flutter)

### Подготовка
- Уверете се, че имате Flutter SDK.
- `cd lib && flutter pub get`

### Основни компоненти
- `lib/api_service.dart` – HTTP/JWT обвъртка към бекенда.
- `lib/screens/map_view.dart` – Leaflet карта с OpenStreetMap.
- `lib/services/` – GPS, офлайн съхранение (sqflite), известия.

---

## 🗄️ База данни

### Схема (MySQL)
- `users`: id, email, password (bcrypt), role (guest/reporter/admin)
- `incidents`: id, lat, lng, status (deceased/wounded/handled), species, photo_url, created_at, reporter_id

### SQL инициализация
- `backend/init.sql` – създава база и таблици.
- Добавен е потребител `admin@roadguardian.local` с парола `admin123`.

## 🎨 Визуален стил
- **Цветове**: Морско синьо фон, оранжеви бутони с градиент, зелено за успех.
- **Шрифт**: Inter с пълна поддръжка на кирилица.
- **Glassmorphism**: Плътен филтър и полупрозрачни панели.
- **Анимации**: GSAP hero анимация, пулсиращи маркери за ранени животни.

---

## 🔧 Технологии
- **Frontend**: Vanilla JS, Leaflet, GSAP, CSS (Glassmorphism)
- **Backend**: Node.js, Express, MySQL2, JWT, Multer
- **Mobile**: Flutter, flutter_map, sqflite, http
- **Карти**: OpenStreetMap (CartoDB Dark) – без API ключове
