# SOS Animal - Демо Версия

## 🚀 Как да стартирате

### Най-лесният начин:
1. Отворете файла `index.html` в браузър
2. Готово!

### Алтернативни начини:
```bash
# С Python
cd demo-frontend
python -m http.server 8000
# Отворете http://localhost:8000

# С Node.js
cd demo-frontend
npx http-server -p 8000
# Отворете http://localhost:8000
```

## 🎯 Функционалности

### Какво работи в демо версията:
- ✅ **Карта с OpenStreetMap** - Детайлна видимост на пътищата
- ✅ **Търсене на адреси** - Nominatim API (само България)
- ✅ **GPS локация** - Геолокация от браузъра
- ✅ **Докладване на инциденти** - Добавяне на маркери в картата
- ✅ **Админ панел** - Пълни CRUD операции върху инцидентите
- ✅ **Плъзгащ се админ панел** - Може да се премества с мишката
- ✅ **Експорт CSV** - Изтегляне на таблица с всички инциденти
- ✅ **Примерни данни** - 7 предварително заредени инцидента из цяла България
- ✅ **Многоезичност** - Превключване между Български/Английски

### Данни:
- **В паметта:** Всички данни се съхраняват в паметта на браузъра за сесията
- **Без сървър:** Няма нужда от backend
- **Примерни инциденти:**
  1. Елен (ранено) - София (Център)
  2. Лисица (умряло) - Пловдив (Стария град)
  3. Диво прасе (ранено) - Варна (Аспарухово)
  4. Костенурка (изчистено) - Бургас (Морската градина)
  5. Сърна (умряло) - Велико Търново (Проход)
  6. Язовец (ранено) - Русе (Брега на Дунав)
  7. Куче (изчистено) - Стара Загора

## �️ Карта

### Търсене на адрес:
- Въведете български адрес
- Автодопълване показва 5 предложения
- Кликнете за полет до локацията
- Координатите се попълват автоматично

### GPS локация:
- Кликнете бутона с прицел 🎯
- Браузърът изисква GPS разрешение
- Картата лети до вашето местоположение

### Маркери:
- Двойно кликване за добавяне на нов маркер
- Попълнете формата и изпратете сигнала
- Маркерът се появява веднага на картата

---

## �️ Админ Панел

### Функции:
- **Плъзгане:** Може да се премества с мишката (дръгнете от хедъра)
- **Списък с инциденти:** Всички инциденти в списък с цветни статуси
- **Детайли:** Кликнете за преглед на детайли
- **Обнови статус:** Промяна на статуса (Ранено/Умряло/Изчистено)
- **Бележки:** Добавяне на бележки към инцидент
- **Изтрий:** Премахване на инцидент
- **Експорт CSV:** Изтегляне на таблица с всички данни

### Размери:
- Ширина: 550px
- Височина: 650px
- Бял фон с тъмно зелени заглавия

## ⚙️ Технически детайли

### Вградени данни:
- `window.currentIncidents` - Масив с инциденти в паметта
- `getInitialData()` - Функция за зареждане на 7 примерни инцидента
- `statusMap` - Мапинг на статуси
- `statusColors` - Цветове за маркери

### Без сървър:
- Няма fetch заявки към backend
- Няма localStorage за токени
- Няма MySQL база данни
- Всичко работи локално в браузъра

### Външни API:
- **Nominatim (OpenStreetMap)** - За търсене на адреси
- **Leaflet Maps** - За картата
- **OpenStreetMap Tiles** - За картата
- Без API ключове
